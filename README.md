## Состав проекта

- `index.html` — главная страница с битами, преимуществами, FAQ и формой консультации.
- `catalog.html` — каталог, фильтры и таблица сравнения.
- `product.html` — карточки и характеристики всех восьми битов.
- `order.html` — отдельная страница заявки.

### JavaScript-файлы

- `js/data.js` — единый массив `products` из восьми товаров.
- `js/catalog.js` — создание карточек и строк сравнения через DOM, поиск, фильтрация, сортировка, счётчик и пустое состояние.
- `js/home-products.js` — вывод дополнительных битов на главной и обновление учебных цен исходных карточек.
- `js/product.js` — вывод дополнительных битов с таблицами характеристик на странице товара.
- `js/players.js` — встроенные YouTube-плееры, внешние ссылки для видео без встраивания и остановка других плееров при запуске нового, если доступен YouTube IFrame API.
- `js/validation.js` — проверка формы на странице заявки и в диалоге, сообщения об ошибках и результате.
- `js/main.js` — вращение пластинки, фотогалерея и ссылка возврата наверх.

## Данные и функции КР №4

В `products` восемь битов с одинаковыми основными полями `id`, `title`, `category`, `price`, `isAvailable`. У каждого есть автор, YouTube ID и дополнительные данные для показа. Четыре бита добавлены по присланным видео. Цены до 5 000 ₽ — **учебные значения для сортировки**; они не подтверждают цену лицензии или право продажи. Условия использования уточняются у правообладателей.

В каталоге карточки создаются через `createElement()` и добавляются в контейнер. Поиск по названию обновляет результаты при вводе, категория и сортировка — при выборе нового значения. Условия применяются вместе; сортируется копия массива. Кнопка «Сбросить фильтры» возвращает исходную выдачу. Счётчик показывает число найденных товаров, а при нуле результатов появляется отдельное сообщение. Заказ из карточки открывает диалог с выбранным битом.

В форме проверяются обязательные поля, длина имени, e-mail, телефон и согласие. Ошибки выводятся рядом с полями, исправляются при вводе. При успешной проверке показывается сообщение о подготовленной заявке. `preventDefault()` исключает отправку: данные не сохраняются и не передаются на сервер.

Для названий товаров, данных формы и сообщений используется `textContent`; пользовательские данные не вставляются через `innerHTML`. События подключены через `addEventListener()`.

## Самостоятельные доработки

- Все восемь битов доступны на главной, в каталоге и на странице с характеристиками.
- Есть таблица сравнения с автором, способом прослушивания и учебной ценой.
- Для шести битов показываются встроенные плееры. Биты 4 и 5 открываются на YouTube, поскольку встроенное воспроизведение для них недоступно.
- Поиск работает без перезагрузки; есть счётчик результатов, пустое состояние и сброс фильтров.
- Форма работает и на отдельной странице, и в диалоге с заранее выбранным товаром; ошибки и результат доступны в самой странице.
- Добавлены фотогалерея, управление вращением пластинки и адаптивное оформление.

## Запуск и проверка

1. В корне проекта запустите `python3 -m http.server 8000` и откройте `http://localhost:8000/catalog.html`.
2. Введите часть названия: число карточек меняется сразу. Выберите категорию и сортировку — они применяются вместе с поиском. Запрос без совпадений показывает пустое состояние. Нажмите «Сбросить фильтры».
3. Нажмите «Заказать» в карточке и проверьте, что бит выбран в диалоге. Отправьте пустую форму, затем заполните её корректно: ошибки и сообщение об успешной подготовке должны появиться на странице.
4. Повторите проверку на `order.html`. Заявка учебная и на сервер не отправляется.
